# Yzen-UI V1.0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 搭建 Yzen-UI monorepo（pnpm workspace），完成双主题设计 token、六个基础组件（带 Vitest 测试）、Showcase 展示站骨架（锚点导航 / 组件注册 / 变体 playground / 复制代码 / 主题切换），达到可本地浏览的 V1.0 状态。

**Architecture:** pnpm monorepo 三部分——`packages/yzen-ui`（组件库：Vue3 + TS + SCSS + CSS Variables，设计 token 全部走 `--yz-*` 变量，浅色默认对齐 beautifului.dev 实测基线 + 深色可切换）；`apps/showcase`（展示站：Vite 应用，构建期通过 `import.meta.glob` 注册组件、读取 `registry/registry.json` 元信息、`?raw` 注入 demo 源码供复制）；根级 `registry/registry.json` 为元信息单一真源（V1.1 Console 接管）。V1.0 不建 `packages/shared`（唯一消费者是 showcase，YAGNI，V1.1 建 Console 时抽取）。

**Tech Stack:** Vue 3.5+ / TypeScript / Vite / SCSS / pnpm workspace / Vitest + @vue/test-utils + happy-dom

## Global Constraints

- **技术栈**：Vue 3 + TS + Vite + SCSS + CSS Variables；包管理器 pnpm（已装 10.28.2）；Node ≥ 20（实测 v26.4.0）
- **npm 包名**：`yzen-ui`；组件前缀 `Yz`（如 `YzButton`）；CSS 类前缀 `yz-`（如 `yz-button`）；CSS 变量前缀 `--yz-`（如 `--yz-page`）
- **视觉基线（浅色默认，对齐 beautifului.dev 实测，来自 PRD 4.1）**：页面 `--yz-page:#fafafb`、画布 `--yz-canvas:#f1f2f3`、表面 `--yz-surface:#fff`、内嵌 `--yz-inset:#f7f8f9`、悬停 `--yz-hover:#f4f5f6`、强悬停 `--yz-hover-2:#e7e9eb`、文字三级 `--yz-ink:#1f2124 / --yz-ink-2:#62656b / --yz-ink-3:#9a9da3`、边框 `--yz-line:#ecedef / --yz-line-strong:#e0e2e5`、强调 `--yz-accent:#0285ff / --yz-accent-ink:#0170dd / --yz-accent-tint:#e9f3ff`、语义 `--yz-green:#189a4d / --yz-orange:#ef720c / --yz-red:#e3474c`（各配 tint `#e8f5ed / #fdf1e5 / #fcecec`）、标签 8 色板 `#3f78ff #25a878 #16a6c7 #92b72d #f09a2f #ee6572 #c84f9d #9a5cff`、深色反色浮层 bg `#25272b` / fg `#f6f7f8` / border `#3a3c40`
- **字体**：Inter（回退 `ui-sans-serif, system-ui`）+ JetBrains Mono（数据元素）；字号 12/14/16/24px；字重 400/500/600；行高 1.25/1.5
- **形状**：圆角 chip 6px / 控件 8px / 卡片 10px / 胶囊 99px；阴影为「1px 发丝线 + 微投影」三档：card / raised / overlay（0 1px 2px + 0 2px 6px + 0 8px 28px，`#101828` 低透明度）
- **动效**：默认时长 150ms；ease-out-strong `cubic-bezier(.23,1,.32,1)`、ease-link `cubic-bezier(.16,1,.3,1)`；全局动效开关变量
- **深色主题**：`html[data-theme="dark"]` 下覆盖 `--yz-*`；深色主题提供玻璃拟态/发光/流光科技质感；组件代码不写死任何视觉值
- **组件开发约束**：所有颜色/阴影/圆角/动效引用 `--yz-*` 变量；props/emits 全 TS 类型定义（`defineProps<T>()`）；Vue 3.5+ `<script setup lang="ts">`
- **测试**：每个组件 `__tests__/*.spec.ts`（Vitest + @vue/test-utils + happy-dom），覆盖渲染、props、emits、插槽
- **提交规范**：每任务独立 commit，信息前缀 `feat:` / `chore:` / `docs:` / `test:`

```ts
  const map: ComponentMap = {}
  for (const [path, mod] of Object.entries(componentModules)) {
    const match = path.match(/components\/([^/]+)\/index\.ts$/)
    if (match) map[match[1]] = mod as Component
  }
  return map
}

export function validateRegistry(
  entries: RegistryEntry[],
  available: string[],
): { ok: true } | { ok: false; errors: string[] } {
  const errors: string[] = []
  const keys = new Set<string>()
  for (const e of entries) {
    if (keys.has(e.key)) errors.push(`重复组件 key: ${e.key}`)
    keys.add(e.key)
    if (!available.includes(e.key)) errors.push(`registry 引用了不存在的组件: ${e.key} (source: ${e.source})`)
    if (!Number.isInteger(e.order)) errors.push(`order 必须为整数: ${e.key}`)
    if (e.variants.length === 0) errors.push(`组件 ${e.key} 至少需要一个变体`)
    for (const v of e.variants) {
      if (!v.label) errors.push(`组件 ${e.key} 存在无 label 的变体`)
    }
  }
  return errors.length ? { ok: false, errors } : { ok: true }
}

export const registryEntries: RegistryEntry[] = (registryJson as RegistryEntry[])
  .filter((e) => e.visible)
  .sort((a, b) => a.order - b.order)

export const componentMap = buildComponentMap()

export const CATEGORY_LABELS: Record<string, string> = {
  basic: '基础组件',
  ai: 'AI 场景',
  advanced: '进阶组件',
}
```

## 风险与说明

- **版本号**：计划中依赖写 `^` 范围（2026-08 时点的稳定大版本）。若 `pnpm install` 时某依赖大版本已升级到计划外（如 Vite 7 / Vue 3.6），以**安装时最新稳定版**为准，仅需保证：Vue ≥3.5、Vite ≥6、Vitest ≥3、sass ≥1.80。
- **`?raw` glob 与异步 glob 同时存在**：ComponentSection 中 `demos`（异步组件）与 `demoModules`（`?raw` 源码）两个 glob 键路径一致，均指向 `demo.vue`，Vite 按 query 区分，无冲突。
- **theme.spec 读文件**：vitest 运行于 Node 环境（happy-dom 只影响组件测试），`node:fs` 可用；`resolve(__dirname, …)` 在 ESM 下用 `resolve(import.meta.dirname, …)`（Node 20.11+ 支持）。
- **`registry.json` 导入**：showcase `resolveJsonModule` 已开（tsconfig.base），json 默认导入可用。
- **ThemeToggle 等展示站组件**：直接 `var(--yz-*)` 引用 CSS 变量（showcase 已通过 alias 引入主题 scss，无需 `$yz-*` 映射）。
